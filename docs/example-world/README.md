# Example D&D Agent Setting: The Ashen Compact

This is a fictional sample setting designed for testing a local multi-agent D&D planning assistant.

It includes:
- Canon lore documents in `lore/`
- Agent behavior files in `agents/`
- Test scenarios in `tests/scenarios/`

The setting is intentionally generic enough to publish publicly, while still containing secrets, factions, conflicting NPC goals, and knowledge boundaries that are useful for testing agent behavior.

## Core Pitch

The realm of **Eldmere** survived a magical disaster called **the Cinderfall** by forming a pact with a sealed fire spirit beneath the capital. Two generations later, the pact is failing. Ash storms return, old wards crack, and powerful factions disagree about whether to renew, break, exploit, or reveal the Compact.

## Suggested First Test

Ask your supervisor:

> What happens if the players reveal to High Warden Selene that Brother Caldus has been hiding evidence that the Ashen Compact is failing?

Expected relevant agents:
- High Warden Selene Marrow
- Brother Caldus Vey
- Lady Isolde Varric
- The Emberbound
- Continuity Keeper
