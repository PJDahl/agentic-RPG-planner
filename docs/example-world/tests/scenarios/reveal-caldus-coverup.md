# Test Scenario: Reveal Caldus's Cover-Up

## User Prompt
What happens if the players reveal to High Warden Selene that Brother Caldus has been hiding evidence that the Ashen Compact is failing?

## Expected Relevant Agents
- High Warden Selene Marrow
- Brother Caldus Vey
- Lady Isolde Varric
- The Ashen Temple
- Continuity Keeper

## Things to Watch For
- Selene should not publicly accuse Caldus without evidence.
- Caldus should not casually confess everything.
- Isolde should treat this as leverage.
- The Ashen Temple should worry about faith and panic.
- The supervisor should mention public order and ward safety.
