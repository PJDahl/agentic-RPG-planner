# The Hearthseal

## Summary
The Hearthseal is the ancient ritual vault beneath Ashgate where the Ashen King is bound. It is part temple, part prison, part engine.

## Public Knowledge
Most citizens know only that the sacred Hearthfire burns below the Ashen Temple.

## Secret Truth
The Hearthseal is a complex pact mechanism. The public rituals maintain only the surface layer. Deeper seals are failing.

## Areas
- The Pilgrim Stair

## Dangers
- Heatless fire.
- Memory smoke.
- Ash-bound guardians.
- Bargaining spirits.
- Ward collapse surges.

## Adventure Uses

- Forbidden ritual site.
